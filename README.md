# KZ AI Opportunities

**KZ AI Opportunities** — веб-приложение, созданное для поиска и просмотра возможностей в сфере искусственного интеллекта в Казахстане. Проект объединяет информацию об образовательных программах, конкурсах, грантах, стажировках и мероприятиях, связанных с ИИ.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите проект:

```bash
npm run dev
```

После запуска откройте в браузере:

```text
http://localhost:3000
```

## Технологии
